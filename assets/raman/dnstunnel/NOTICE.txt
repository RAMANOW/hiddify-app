Raman VPN — "DNS قطعی" (shutdown DNS tunnel) tab — third-party notices

This tab runs open-source DNS-tunnel clients on the phone, each as a local server on 127.0.0.1
that the Hiddify core (Raman VPN's normal VPN) uses as its only (SOCKS5) outbound.

1. Soar — https://github.com/getlantern/soar (tag v0.2.4)
   By the Lantern team (https://lantern.io).
   Licensed under the Apache License, Version 2.0 (LICENSE-soar.txt). The upstream repository has
   no NOTICE file. Soar is used unmodified as a Go library by Raman VPN's small SOCKS5 front end
   (raman/dnstunnel/soarsocks in the Raman VPN source). Soar's bundled Iran resolver and range
   lists come from KevinNet DNS (MIT, THIRD_PARTY-soar-data.md).

2. CottenDNS — https://github.com/TaJirax/cottenDNS (tag v2026.11.04.181149-ac8e86e), by tajirax,
   MIT License (LICENSE-cottendns.txt). Built unmodified from that tag (its cmd/client).
   CottenDNS is a derivative of StormDNS by NullRoute1970 (MIT), itself a derivative of
   MasterDnsVPN by Amin Mahmoudi (MIT). Their notices are kept in LICENSE-cottendns.txt.
   CottenDNS's own third-party notices (THIRD_PARTY_NOTICES-cottendns.md) cover its CottenMax
   transport derived from Soar v0.2.3 (Apache-2.0), KevinNet DNS data (MIT), quic-go (MIT,
   LICENSE-quic-go.txt) and qpack (MIT, LICENSE-qpack.txt).

3. dnstt — https://www.bamsoftware.com/software/dnstt/ (tag v1.20260501.0), by David Fifield.
   Public domain (CC0 1.0, LICENSE-dnstt.txt). libdnstt.so is dnstt-client, built unmodified.
   (Added in Raman VPN 1.8.2.)

4. Slipstream — https://github.com/EndPositive/slipstream (commit e158a681), by EndPositive.
   Apache License 2.0 (LICENSE-slipstream.txt, with the licenses of the code compiled into it:
   picoquic MIT, picotls MIT, micro-ecc BSD-2-Clause, cifra CC0, lua-resty-base-encoding MIT,
   quick_arg_parser MIT, SPCDNS LGPL-3.0). libslipstream.so is its client, built with these changes
   made by raman/dnstunnel/build-slipstream.sh (Apache-2.0 section 4b):
     - picoquic is configured without OpenSSL (WITH_OPENSSL=OFF) and without picotls "fusion", so
       TLS uses picotls "minicrypto";
     - picoquic's cmake/FindPTLS.cmake no longer lists the picotls-openssl library;
     - the client's local TCP listener binds 127.0.0.1 instead of 0.0.0.0.
   (Added in Raman VPN 1.8.2.)

5. MasterDnsVPN — https://github.com/masterking32/MasterDnsVPN (tag v2026.11.18.210322-7198b45), by
   Amin Mahmoudi (MasterkinG32). MIT License (LICENSE-masterdnsvpn.txt). libmasterdns.so is its
   client (cmd/client), built unmodified. (Added in Raman VPN 1.8.2.)

Licenses of every other Go module compiled into the Go engines: LICENSES-go-modules.txt.

Telegram channel (https://t.me/s/whitedns). Raman VPN is not affiliated with that channel or with
the authors above; no code, assets, name or UI of any other app are used.
