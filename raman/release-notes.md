### New in 1.3 (based on Hiddify 5.9.8)
- ⚡ Smart keep-top: only the fastest proxies stay active, the rest sleep on their own — far less battery, data and memory
- 🌍 Pick a region and refresh instantly from the cache of the last connection
- 📌 Long-press a proxy to pin it
- 🚀 No more lag on Android; steadier WireGuard and UDP
- ✨ Interface refinements and crash fixes
- 🛡️ Shield unchanged: all 1.2 Shield settings work as before (connection protocol, beast mode, CDN and Conduit options stay "coming soon")

### Raman VPN
- Two tabs: **Raman** (your profiles and configs) and **Shield** (one-tap connect through the Psiphon network, no server needed)
- Shield: exit-country picker, use as extra security or unblocker for Raman profiles, Shield settings (own split tunneling, upstream proxy, network sharing, disable timeouts, sound/vibration, stealth notifications, open a website after connecting, language, disguise icon, always-on VPN)
- Disguise icon: show the app as Calculator, Weather, Notes or Clock
- Smart DNS, network checker, Iran defaults

The core library is the official [hiddify-core](https://github.com/hiddify/hiddify-core) 5.9.8 release, same license. Raman VPN is based on [Hiddify](https://github.com/hiddify/hiddify-app); all credit for the app and its core goes to the Hiddify team.

Install `RamanVPN-Android-universal.apk` if you are not sure which one fits your phone. An APK signed with a different key than the one you have installed can't update over it: uninstall the old version first in that case.
